## 3. 기법 (Techniques)

| 약어 | 영문 풀네임 | 한글 설명 | 사용처 |
|---|---|---|---|
| SE | Semantic Entropy | N=10 샘플을 entailment 의미 클러스터링 후 entropy (Farquhar Nature 2024) | RQ1·관점 A |
| SEPs | Semantic Entropy Probes | hidden state로 SE를 단일 forward에서 예측 (Kossen NeurIPS 2024) | 관점 A |
| SC | Self-Consistency | N개 샘플 다수결 + consistency rate (Wang ICLR 2023) | 이세훈 노트북 |
| CoT | Chain-of-Thought | 답 전 추론 단계 자연어 풀이 (Wei 2022) | SC 환경 |
| Layer Probe | Layer-wise Linear Probe (Exp06) | 각 layer hidden state에 로지스틱 회귀, layer별 AUROC 측정 | 관점 B 메인 |
| Sublayer Probe | Sublayer Probe (Exp12) | 한 layer를 attn_stream / mlp_stream 분리, 인코딩 주체 판별 | 관점 B 메커니즘 |
| Logit Lens | Logit Lens (Exp11) | 중간 layer hidden → LM head → vocab entropy 추적 | Type I/II 구분 |
| Greedy Decoding | Greedy Decoding | T=0, 확률 최대 토큰 선택 | SC baseline |
| Sampling | Stochastic Sampling | 확률 분포에서 무작위 토큰 추출 | SE·SC |
| Temperature (T) | Temperature | softmax 평탄도. T=0 greedy, T=0.7 stochastic | SC 환경 |
| Top-p (Nucleus) | Top-p Sampling | 누적 확률 p까지 후보 사용 | 디코딩 |
| Top-k | Top-k Sampling | 상위 k개 토큰 사용 | 디코딩 |
| ⭐ Activation Patching | Activation Patching (Meng et al. ROME, 2022) | 모델 A의 특정 layer 출력을 모델 B에 강제 주입, 인과 효과 측정 | 본인 실험 1 |
| ⭐ Steering Vector | Steering Vector (Subramani·Turner) | d = mean(wrong) - mean(correct) 방향으로 hidden state 조작, 생성 변화 측정 | 본인 실험 2 |
| ⭐ Multi-metric Trajectory | Multi-metric Layer Trajectory | layer별 Fisher·Silhouette·MI·attention entropy 등 다중 지표 동시 추적 | 본인 실험 3 |
| ⭐ Verbalized Confidence | Verbalized Confidence (Xiong 2024) | 모델이 자기 확신도를 언어로 출력하게 유도 (예: "I am 70% sure") | 우창님 Exp05 |
| ⭐ Token Entropy | Token-level Logit Entropy | 토큰 생성 시 logit 분포 Shannon entropy. Type I 모델에서 실패 (어휘 불확실성 약함) | 우창님 Exp01 |
| ⭐ Intervention | Probe-based Intervention | layer probe로 hallucination 탐지 후 재샘플링. 우창님 Exp10 부정 결과 (Δacc = +0.000) | 우창님 Exp10 |
| ⭐ Hidden State Geometry | Hidden State Geometric Analysis | hidden state 차원 축소·분리·representation 분석 | 우창님 Exp11 |

| LoRA | Low-Rank Adaptation | 저랭크 행렬만 학습. PEFT 기법 | 실험 5 (옵션) |
| ⭐ QLoRA | Quantized LoRA (Dettmers NeurIPS 2023) | 4-bit 양자화 base + LoRA adapter. 7B 모델 12-15GB로 학습 가능 | 실험 5 (계획) |

## 7. 개념 (Concepts) — v2 대폭 보강

| 약어 | 영문 풀네임 | 한글 설명 | 사용처 |
|---|---|---|---|

| ⭐ Type II-b | Type II-b (Late Lexical Growth) | 기하학적 분리(중반) 후에도 어휘 불확실성이 후반까지 계속 성장. Qwen-7B 대표 | v3 메인 framing |

| Adaptive SE | Adaptive Semantic Entropy | early stopping으로 SE 샘플 수 동적 결정 | 실용 제안 |
| Peak Layer | Peak Layer | hallucination 탐지 AUROC가 최고인 layer | 메커니즘 |
| Peak Depth | Peak Relative Depth | peak_layer / n_layers (0~1). 본 연구 핵심 지표 | v3 메인 |
| ⭐ rel_d band [0.55, 0.81] | H3-revised relative depth band | Standard SFT/Instruct 그룹 peak rel_depth 평균 0.682 ± 1 std 0.131. 가설 평가 기준 구간 | trajectory |
| Key-Value Memory | Key-Value Memory | MLP를 key-value 저장소로 해석 (Geva EMNLP 2021). factual 지식 인코딩 메커니즘 | Type I 해석 근거 |
| Attention Sink | Attention Sink | 초반 토큰에 attention 비정상 집중 (Gu ICLR 2025) | Phase 2 폐기 사유 |

| ⭐ Detection ≠ Correction | Detection vs Correction | 우창님 Exp10 핵심 발견 ⑧. "탐지 가능 ≠ 교정 가능". probe 탐지 후 재샘플링으론 정확도 변화 없음 (n=75, Δ=+0.000) | 실용 한계 |
| ⭐ MMLU 탐지 역전 | MMLU Detection Inversion | 정확도 > 90% 시 hallucination 분류기 AUROC가 0.5 미만으로 역전. 데이터셋 정확도 극단 시 구조적 한계 | 우창님 Exp09 |
| ⭐ Linear Representation Hypothesis | Linear Representation Hypothesis (Park 2024) | 개념이 hidden space의 linear direction으로 인코딩된다는 가설. Steering Vector의 이론적 근거 | 본인 실험 2 |
| ⭐ scaling 음의 상관 | Parameter-Detection Negative Correlation | 모델 클수록 hallucination 탐지 어려움. 우창님 Exp07 r=-0.86 | 우창님 핵심 발견 ② |

## 9. 기호·약식 표기

| 기호 | 의미 | 사용 맥락 |

| T | Temperature | 샘플링 온도 |
| L21, L2 | Layer index | 21번째·2번째 Transformer layer |
| rel_d, rel depth | Relative Depth | layer_index / n_layers (0~1) |
| n_cells | (Model, Dataset) Cells | 실험 측정 단위 수 |
| gap | AUROC Gap | 두 방법 AUROC 차이 |
| Δ | Delta (변화량) | 두 조건 차이 |
| pp | Percentage Points | 백분율 차이 단위 |
| ⭐ α | Steering Strength | h ← h + αd 의 강도. 본인 실험 2에서 α ∈ {-2, -1, -0.5, 0, 0.5, 1, 2} |
| ⭐ β | DPO beta | DPO loss 의 KL 정규화 강도. 본인 실험 5 default 0.1 |
| ⭐ ||·|| | Vector Norm (L2) | hidden state 또는 direction vector 크기 |
| ⭐ μ_c, μ_w | Class Mean (correct·wrong) | hidden state 평균 (정답·오답 그룹) |
