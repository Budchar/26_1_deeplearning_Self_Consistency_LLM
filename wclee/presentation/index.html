Mechanism — Sublayer Probe (Exp12)

MLP vs Attention — 누가 인코딩하나?

각 레이어를 attn_stream (Attention 후) / mlp_stream (MLP 후) 두 지점으로 분리 탐침

Mistral-v0.3 — Type I (Early MLP)

EXAONE-3.5 — Type II (Late Attn)

Type I (Mistral-v0.3, NousHermes)
초반 L2–4 MLP가 주도 · 사실성 SFT+DPO
Type II (EXAONE, Qwen)
후반 Attention이 주도 · vocab 불확실성 성장
Conclusion

한 문장으로 정리하면

사실성 SFT 데이터(OpenHermes)로 학습 후 DPO를 적용하면,
hallucination 인코딩이 후반 레이어에서 초반 MLP (L2–4)로 이동한다.
