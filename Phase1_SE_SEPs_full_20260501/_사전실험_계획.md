## Phase 1 — Semantic Entropy + SEPs (3~5일)

### 1.1 핵심 가설 (모두 falsifiable)

| ID | 가설 | 측정 메트릭 | 기각 조건 |
|---|---|---|---|
| **H1** | SC × SE 보완성 — SE 높은 질문에서는 SC majority vote가 정확도 향상에 통계적으로 유의하지 않다 (Wilcoxon p > 0.05). SE 낮은 질문에서는 유의 (p < 0.05). | SC@N accuracy stratified by SE quartile | SE 분위 무관하게 SC 동일 효과 시 H1 기각 |
| **H2** | Pre-hoc (SEPs) AUROC vs Post-hoc (SE) AUROC gap이 모델 size에 따라 변한다. 1B에서 gap이 가장 크고 (>0.10), 7B에선 거의 0. | AUROC(SEPs) − AUROC(SE) by 모델 크기 | gap이 모든 크기에서 0±0.05면 H2 기각 |
| **H3** | Hidden state probing에서 SE 정보가 emerge하는 layer 깊이가 모델 크기에 따라 다르다. | Layer × AUROC heatmap, peak layer position (relative depth 0~1) | peak layer가 모든 크기에서 동일하면 H3 기각 |
| **H4 (보조)** | Cost-aware Adaptive SE — confidence-aware하게 N을 동적 조절하면 평균 sample 비용이 30%+ 감소하며 AUROC는 ±0.02 안. | (Adaptive AUROC, Adaptive 평균 N) vs (Fixed AUROC, Fixed N) | 비용 절감 < 20% OR AUROC 차이 > 0.05 시 H4 기각 |

### 1.2 실험 설계

**모델 (5종, 모두 5070 단독)**:
- Qwen/Qwen2.5-1.5B-Instruct (fp16, 메인)
- Qwen/Qwen2.5-3B-Instruct (fp16)
- Qwen/Qwen2.5-7B-Instruct (**bnb 4-bit**, ~4GB VRAM, 5070 OK)
- meta-llama/Llama-3.2-1B-Instruct (fp16)
- meta-llama/Llama-3.2-3B-Instruct (fp16)

**데이터셋 (3종, 각 1000문항)**:
- TriviaQA `rc.nocontext` validation
- Natural Questions `nq_open` validation
- SQuAD validation (context 제거)

**Sampling 파라미터**:
- N = 10 per question
- temperature = 1.0, top_p = 0.95
- max_new_tokens = 64

**Entailment 모델 (semantic clustering)**:
- 메인: deberta-v2-xlarge-mnli
- 검증용: `Qwen2.5-7B`로 self-judge

**SEPs probe 학습**:
- 입력: 각 layer hidden state (last token position)
- 출력: SE class (high/low binary, threshold = median)
- 모델: Logistic Regression + small MLP (2-layer)
- 학습: 80/20 split per dataset

**Cost-aware Adaptive SE 알고리즘**:
```
1. 첫 N=3 sample 생성 → SE 측정
2. SE > threshold_high → 추가 N=7 sampling (총 N=10)
3. SE < threshold_low → 추가 sampling 안 함 (N=3)
4. 중간 영역 → 추가 N=2 (총 N=5)
```

- **Brier score**
- **AURC** (Area Under Risk-Coverage)

## Phase 2 — C2 Attention Sinks Emergence (3~4일)

### 2.1 핵심 가설

| ID | 가설 | 측정 | 기각 조건 |
|---|---|---|---|
| **H1** | GPT-2 124M에 P0 sink circuit이 학습 5K~15K step 사이에 emerge. circuit은 layer 0~2의 head 2~4개로 구성. | Position 0 attention weight × layer × step | step 50K까지 sink 안 보이면 기각 |
| **H2** | P0 회로 head 마스킹 → PPL 5%+ 악화 + 다른 위치(P1, P2)로 sink 옮겨가지 않음. | PPL Δ + 마스킹 후 attention pattern | 대체 회로 형성 시 H2 기각 |
| **H3** | Sigmoid attention / Softpick / Softplus → P0 회로 emerge X + length extrapolation 향상 (4× train length 평가) | sink 강도 + long-context PPL | sigmoid에서도 sink emerge 시 기각 |
| **H4** | Sink 회로 형성 시점이 induction head 형성 시점과 일관된 순서 (sink 먼저 또는 동시). | Sink emergence step vs induction emergence step | 무작위 순서면 H4 기각 |

### 2.2 실험 설계

**Architecture variants (4종)**:
1. **Standard GPT-2** (softmax attention)
2. **Sigmoid attention** (Softmax → Sigmoid)
3. **Softpick** (arXiv:2504.20966 구현)
4. **Softplus attention** (변형)

**모든 변형 공통**:
- 모델: GPT-2 124M (12 layer, 12 head, d=768)
- 학습 데이터: OpenWebText subset (~5B tokens, streaming)
- Optimizer: AdamW (lr=3e-4, wd=0.1, betas=(0.9, 0.95))
- Schedule: cosine + 1K warmup
- Batch: 16 × 1024 seq = 16K tokens/step
- Steps: 50K (총 ~800M tokens)

**체크포인트**: step 0, 100, 500, 1K, 2K, 5K, 10K, 15K, 20K, 30K, 50K (총 11개)

**Sink 회로 식별**:
- Per layer: average attention weight to position 0 (over batch + token positions)
- Per head: same, head별로
- "Sink head": P0 attention > 0.5 (threshold)
- 회로 = sink head 집합 (layer 0~2 위주)

**Causal intervention**:
- Sink head 마스킹 (attention weight = 0)
- 마스킹 후 PPL 측정 + attention pattern 시각화

**Long-context evaluation**:
- Train seq=1024 → test seq={1024, 2048, 4096} (zero-shot)
- PPL by context length

**Induction head 측정** (H4용):
- Repeated sequence test (Olsson et al.)
- Induction score per head per step

### 2.3 메트릭

- **Sink strength**: 평균 P0 attention by layer × step
- **Sink head count**: P0 attn > 0.5인 head 수
- **Causal mask PPL Δ**
- **Long-context PPL** (1×, 2×, 4× train length)
- **Induction score** (Olsson 측정법)

### 2.4 시간 추정

| 단계 | 시간 |
|---|---|
| Standard GPT-2 124M × 50K step | ~12시간 (5070, bf16) |
| × 4 variants | ~48시간 |
| 체크포인트 분석 (sink 식별 + induction) | ~10시간 |
| Causal intervention | ~5시간 |
| Long-context eval | ~5시간 |
| 시각화·통계 | ~5시간 |
| **합계** | **70시간 (~3~4일)** |

## Phase 3 — C3 Grokking Early-Warning (3~4일)

### 3.1 핵심 가설

| ID | 가설 | 측정 | 기각 조건 |
|---|---|---|---|
| **H1 (Generalization)** | Modular arithmetic / parity / sparse parity / Dyck / SCAN 5개 task 모두에서 grokking 발생 + commutator defect lead-time이 superlinear power-law (alpha 0.9~1.3). | alpha fit + R² | alpha < 0.7 또는 R² < 0.7 시 기각 |
| **H2 (Architecture)** | 같은 task에서 Mamba (state-space)는 commutator defect 신호가 약하거나 다른 lead-time scaling을 보인다 (alpha 차이 > 0.3). | alpha(Transformer) − alpha(Mamba) | 차이 < 0.1 시 H2 기각 |
| **H3 (Causal)** | 학습 중 non-commutativity를 인위적으로 증폭 (gradient projection 조작) → grokking 30%+ 빠름. 직교 gradient flow 억제 → 50%+ 지연. | grokking step Δ vs baseline | 변화 < 10% 시 H3 기각 |
| **H4 (보조)** | Commutator defect 신호의 detection lead time은 학습률(lr)과 weight decay에 단조 의존. | lead-time vs lr/wd | 무관하면 H4 기각 |

### 3.2 실험 설계

**Tasks (5종)**:
1. **Modular arithmetic** (mod 97, 80% train / 20% test)
2. **Parity** (binary string parity, 8-bit)
3. **Sparse parity** (k=3 of 10 bits)
4. **Dyck** (balanced parentheses, depth 4)
5. **SCAN** (subset, basic command translation)

**Architectures (3종)**:
1. **2L Transformer** (50K params, attention only)
2. **Mamba** (~100K params, official mamba-ssm 라이브러리 또는 HF MambaForCausalLM)
3. **Linear-attention** (Performer-style baseline)

**Seeds**: 3 per (task × arch) configuration → 5 × 3 × 3 = 45 runs

**학습**:
- Up to 200K step (또는 grokking 발생 시 종료)
- Optimizer: AdamW
- 매 1K step마다 체크포인트 + train/test acc + commutator defect 측정

**Commutator defect 측정**:
- 한 batch에서 두 순서로 gradient 적용:
  - Order A: g_A then g_B
  - Order B: g_B then g_A
- ||θ_A - θ_B|| 측정 = commutator defect
- 매 1K step

**Lead-time scaling fit**:
- 정의: defect detection step → grokking step 거리
- Power-law fit: lead_time = a × N_data^alpha

**Causal intervention** (H3):
- gradient projection 조작:
  - 증폭: g_proj = g + λ × [g, g_prev] (commutator term 추가)
  - 억제: g_proj = g - projection of g onto g_prev (직교화)
- 변형 모두 같은 조건에서 grokking 비교

**H4 ablation**:
- lr × wd grid: lr ∈ {1e-3, 3e-3, 1e-2, 3e-2}, wd ∈ {0, 0.01, 0.1}

### 3.3 메트릭

- **Grokking step**: test acc > 95% 도달 step
- **Commutator defect**: ||θ_A - θ_B|| 시계열
- **Lead-time**: defect signal 출현 → grokking step 거리
- **Power-law alpha + R²**
- **Train/test acc curve**
