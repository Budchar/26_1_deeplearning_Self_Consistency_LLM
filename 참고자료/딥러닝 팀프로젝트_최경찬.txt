최경찬 — 딥러닝 팀프로젝트

1. 메인 후보: Semantic Entropy
   설명: 이 논문은 제가 추천한 것이 아니라, 이우창님이 주신 LLM 논문 리스트를 검토하던 중 확인했고, 내용이 좋아 보여 간단히 검토해봤습니다
   핵심 아이디어: 같은 질문을 여러 번 물어보면, 진짜 아는지 모르는지 드러난다
   직관: 친구에게 같은 질문을 5번 물었을 때 답이 비슷하면 아는 것, 계속 바뀌면 모르는 것
   정리: 답의 “흩어짐” 정도를 수치화한 것이 Semantic Entropy
   해석: 값이 크면 환각 가능성 높음, 값이 작으면 신뢰 가능성 높음
   한계: 여러 번 질문해야 해서 비용 큼, 답을 만든 뒤에만 판단 가능

2. 보완 후보: Semantic Entropy Probes(SEPs)
   논문: Semantic Entropy Probes — Robust and Cheap Hallucination Detection in LLMs
   저자: Jannik Kossen, Jiatong Han, Muhammed Razzak, Lisa Schut, Shreshth Malik, Yarin Gal
   핵심 아이디어: 답을 여러 번 듣지 말고, 생각하는 과정에서 이미 드러난 신호를 보자
   직관: 친구가 답을 쓰는 동안 표정이나 망설임을 보면 확신 있는지 알 수 있음
   정리: hidden state를 이용해 “이 답이 흔들리는지” 미리 예측
   장점: 한 번만 계산, 답 나오기 전 판단 가능

3. 제안 방향 (1,2번 결합)
   이 두 개를 합쳐서 이런 방향으로 가보면 어떨까요?

* “답을 보고 판단(SE)” vs “생각 과정에서 미리 판단(SEPs)” 비교
* 모델 크기가 커질수록 “확신 신호”가 더 잘 드러나는지 분석
* 확신 없는 경우에만 여러 번 질문하도록 하는 효율적인 전략 설계

쉽게 정리하면:
“모르면 여러 번 생각하게 하고, 알면 바로 답하게 만드는 구조”

4. 추가로 제가 추천하는 논문

Attention Sink
논문: How Attention Sinks Emerge in Language Models
저자: (arXiv 2026 논문, 저자 미상 제출 상태)
설명: 모델이 답을 만들 때 특정 토큰(초기 위치)에 이유 없이 계속 attention을 주는 현상
직관: 학생들이 문제 풀 때 의미 없는 1번 학생을 계속 쳐다보는 이상한 습관
확장 아이디어: 이 구조를 없애면 모델 성능이 좋아질까?

Grokking
논문: Early Warning Signals for Grokking via Loss Landscape Geometry
저자: (arXiv 2026 논문, 저자 미상 제출 상태)
설명: 모델이 “외우기 단계 → 이해 단계”로 넘어가기 전에 나타나는 신호 탐지
직관: 아이가 곱셈을 외우다가 어느 순간 이해하는데, 그 직전에 이상한 변화가 나타남
확장 아이디어: 그 신호를 이용해 학습을 더 빠르게 만들 수 있을까?

5. 정리
   SE + SEPs: 안정적이고 바로 실험 가능, 기존 연구와 연결 쉬움
   Attention Sink: 모델 내부 구조 이해 중심
   Grokking: 가장 흥미롭고 이론적인 주제

결론:
SE + SEPs 방향이 가장 무난하면서 확장 가능성이 높아 보입니다

한 줄 요약:
“모델이 스스로 ‘모른다’를 알아차리게 만들 수 있는가”
